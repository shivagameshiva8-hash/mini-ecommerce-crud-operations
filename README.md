# Mini E-Commerce CRUD Application

A mini e-commerce web application built using Node.js, Express.js,
MongoDB and Mongoose.

## Features

- Create products
- View products
- Update products
- Delete products

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- EJS
- HTML
- CSS
- JavaScript

## CRUD Operations

- Create - Add a new product
- Read - View products
- Update - Edit product details
- Delete - Remove a product


## Search & Filtering

Users can search for products and filter products based on their category.
